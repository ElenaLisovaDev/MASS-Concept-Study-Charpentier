# Maritime Autonomous Surface System (MASS) Concept Study

## Agentic Engineering for Uncrewed Surface Vessel (USV) Design, Regulatory Analysis, and Digital Development

# Agentic Engineering Approach

The project uses AI agents as engineering collaborators.

Agents may support:

### Regulatory Agent

- Regulation review
- Requirement extraction
- Gap analysis
- Compliance mapping

### Systems Engineering Agent

- SysML consistency checks
- Functional decomposition
- Architecture recommendations
- Traceability validation

### Design Agent

- Concept exploration
- Parametric trade studies
- Design optimization suggestions

### UI/UX Agent

- Interface generation
- Dashboard concepts
- Human-machine interaction analysis

### Documentation Agent

- Technical report drafting
- Architecture summaries
- Verification matrix generation

All AI-generated outputs should be reviewed critically and validated through engineering judgement.
